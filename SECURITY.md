# Security policy

Report a suspected vulnerability privately through [GitHub Security
Advisories](https://github.com/voidfreud/mcp-gateway/security/advisories/new).
Do not include secrets, tokens, private endpoints, exploit details, or affected
customer data in a public Issue, pull request, commit, CI log, or receipt.

Security fixes are supported for the current 1.x release line. We aim to
acknowledge private reports, but do not promise a response-time SLA. If private
advisories are unavailable, open a public Issue only to request a private
reporting channel; include no vulnerability details.

For the product threat model and safe configuration guidance, see
[docs/security.md](docs/security.md).
