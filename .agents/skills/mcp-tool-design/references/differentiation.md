# Differentiation

Read this when a task could plausibly select more than one tool.

1. Inventory the enabled surface in the user-approved scope.
2. Group tools by the task a person or agent would bring to them.
3. Research actual differences in authority, coverage, freshness, input shape,
   output, cost, authorization, and failure mode.
4. Write a route for each overlap: use this tool for _this situation_; use its
   sibling for _that situation_. State a sequence only when both are needed.
5. Encode the distinction on every affected surface, not just one description.
6. Check a representative task against names, instructions, descriptions, and
   parameters without relying on the author's memory.

Do not invent a distinction to preserve two equivalent tools. Raise a scoped
issue when the evidence shows duplication, an unresolvable overlap, or a need
to change topology.
